## Outline

### Quick Answer (top, callout)
> **Quick answer:** A 12-piece Wera Kraftform screwdriver set fits a 6×3 Gridfinity bin (252×126mm interior). Photograph the set arranged in your preferred order on a sheet of A4 paper. Trace each handle into a precision-fit cavity using TracetoForge multi-tool mode. Set wall height to 25-30mm so the handles are easy to grab. Print in PETG at 0.2mm layer height — total print time ~6 hours, ~$3-4 in filament. The same template works for the Wera 367 (PH/PZ/SL) set, the 334/6 (slotted/Phillips), and the 932 chisel-grip series.

### What You'll Need
- A Wera Kraftform set (works for any series — 334, 367, 932)
- A phone with camera
- A sheet of A4 paper
- A 3D printer (any FDM)
- ~$3-4 in PETG filament

### Step 1: Plan the Layout
Spread the screwdrivers handle-down on the paper in the order you want them in the bin. Leave 5mm between handles. The paper sets the bin footprint — 6×3 (252×126mm) fits 12 standard Wera handles; 4×3 fits 8.

### Step 2: Photograph
*(link to A4 photo tips)* Top-down shot, even lighting, 30cm above. The bright handles trace cleanly against white paper.

### Step 3: Trace + Tune in the Editor
- Sensitivity 4-6 works for most Kraftform handles
- Use multi-tool mode: each handle becomes a separate cavity
- Set Gridfinity Bin mode (NOT custom tray)
- Cavity depth: 25mm (handles are ~22mm diameter; 25mm gives clearance)
- Tolerance: 0.5mm (Wera handles are smooth; 0.5mm tolerance keeps them snug but liftable)

### Step 4: Add Finger Notches
Click each cavity to add a finger notch — without it, the handles sit flush in the bin and are hard to grab. Notch depth: 8-10mm.

### Step 5: Export and Print
- STL or 3MF
- PETG, 0.2mm layer, 15% infill, 3 walls, no supports
- Print time: ~6 hours for a 6×3 bin
- Filament: ~$3-4

### Step 6: Drop In and Test
Place in any Gridfinity baseplate. Verify each handle slides in with light pressure and lifts out with a fingertip. If too tight, sand the cavity walls or reprint with +0.2mm tolerance.

### Variations
- **Wera 932 chisel-grip:** the squared-off handle profile traces differently — shoot from straight above, sensitivity 5-6
- **Bicolor handles (Wera Kraftform XL):** the auto-trace catches the full silhouette regardless of color
- **Stubby drivers (Wera 168i):** use a 4×2 bin layout
- **Wera ratcheting bit driver:** trace the open position so the cavity allows the ratchet to drop in
